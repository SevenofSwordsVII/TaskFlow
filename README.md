# TaskFlow

Production-oriented multi-tenant SaaS project management platform.

## Architecture

- Modular Monolith
- Pragmatic Vertical Slice Architecture
- FastAPI + PostgreSQL + SQLAlchemy Async
- React + TypeScript + Vite
- TanStack Query for server state
- Zustand for local interactive state
- Kanban Board/List/Task kept inside one cohesive `kanban` module
